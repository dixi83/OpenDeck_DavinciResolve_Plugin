# Contributing

Thanks for contributing to the DaVinci Resolve OpenDeck plugin.

Unless a contribution is explicitly marked otherwise, contributions to the
plugin code and original artwork are provided under GPL-3.0-only. Do not add
third-party assets without documenting their source and license in
`THIRD-PARTY-NOTICES.md`.

## Icons

- Put action icons used by the plugin in `assets/icons/` and reference them from `assets/manifest.json`.
- Use a clear, lowercase filename that matches the action, such as `undo.png` or `redo.png`.
- Keep reusable or not-yet-mapped icons in `assets/icons/`; document their intended use here or in the README.
- Keep upstream icon packs and their license/attribution files intact in `assets/icons/iconpack/`.
- When contributing original artwork, include the creator name or handle in the README's icon credits.

### Existing custom contributions

- `assets/icons/undo.png` and `assets/icons/redo.png` are original icons created and contributed by Martijn (DiXY).
- `assets/icons/blank.png` is a blank icon contributed by Martijn (DiXY), available as a base for future OpenDeck actions.
